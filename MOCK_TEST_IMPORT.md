# Imported mock test

35 questions integrated; 13 original embedded illustrations retained. The original 96 questions remain. Concept overlaps are distinct, source-labelled practice variants, not exact duplicates.

Simple mode gives two choices; test practice preserves all four document choices. Images without a supplied illustration reuse the closest existing scene. The images checkbox applies to both imported pictures and generated scenes.

The supplied title claims alignment with Dubai Municipality; publisher and approval status are not established. The app does not label this as an official question bank.

## Clarifications

- Question 5: Replaced ambiguous rice/raw-chicken comparison with cooked chicken, matching the Code definition of high-risk ready-to-eat food.
- Question 8: Narrowed the question because washing before eating is also a valid hygiene action.
- Question 9: Clarified that 20 seconds refers to scrubbing, not the complete wet/soap/rinse/dry routine. CDC is the verification source.
- Question 11: Changed below 5°C to 5°C or below.
- Question 12: Clarified minus 18°C as a preferred frozen-storage quality target, rather than a definition of when all food freezes.
- Question 14: Removed a universal once-daily claim; the workplace monitoring schedule determines frequency.
- Question 15: Removed the second potentially correct answer about vegetables above meat; specified protected ready-to-eat food.
- Question 17: Restricted the two-hour answer to Food Code section 3.3(a); cold food, cooling and other processes have different rules.
- Question 20: Specified outside hot/cold limits, rather than above a safe limit for every delivery.
- Question 21: Changed kills germs to reduces harmful germs; sanitizing is not sterilization.
